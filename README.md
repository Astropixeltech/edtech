# Astropixel Learn EdTech Platform (astropixel.tech)

Astropixel Learn is a 100% independent, standalone EdTech (Learning Management System) application powering **astropixel.tech**.

## 🌐 Project Domain & Access Points

- **Primary Platform Home**: [https://astropixel.tech](https://astropixel.tech)
- **Courses Catalog**: [https://astropixel.tech/courses](https://astropixel.tech/courses)
- **Education Admin Panel**: [https://astropixel.tech/admin](https://astropixel.tech/admin)
- **Student Auth Portal**: [https://astropixel.tech/student/login](https://astropixel.tech/student/login)
- **Teacher Auth Portal**: [https://astropixel.tech/teacher/login](https://astropixel.tech/teacher/login)

---

## 🚀 Key Features

- **Academic & Admission Prep Courses**: Video lessons, BUET/Medical/DU admission tracks, HSC Science & SSC courses.
- **Student Dashboard**: Enrolled courses, video player, course progress tracking, certificates, and profile management.
- **Teacher Portal**: Course management, module/lesson builder, student analytics, and withdrawal system.
- **Education Admin Panel**: Full governance of courses, video lessons, enrollment approvals, payment integrations, coupons, and CMS content.
- **Digital Certificates**: Automatic certificate generation and public verification system.

---

## 🛠️ Tech Stack & Setup

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Shadcn UI
- **Backend & Database**: Supabase (PostgreSQL, Auth, Storage, Edge Functions) & Node.js Express Server
